This repository provides a clear and practical overview of the Block Blast puzzle game.

## 📌 About Block Blast

Block Blast is a classic block-placement puzzle game where players drag different shapes onto a board to clear horizontal and vertical lines.  
The challenge increases as space becomes limited, requiring better planning and positioning with each move.

This guide is designed for:
- New players learning the basics  
- Casual players aiming for higher scores  
- Puzzle fans who enjoy strategy-based games

## 🧠 Gameplay Strategy Highlights

- Keep the board open by clearing lines early  
- Avoid stacking blocks in one area  
- Plan moves ahead instead of reacting late  
- Focus on combo chains rather than single clears  
- Save space for large block shapes  

These small adjustments can make a big difference during extended gameplay.
